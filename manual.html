  • สรุป_KPI_โบนัส: คะแนน เกรด A–D และยอดออกนอกพื้นที่ ครบ 17 คน
2. เปลี่ยน PIN / ตั้งค่า

เปลี่ยนครั้งเดียว ใช้ได้ทุกเครื่อง

กด ตั้งค่าระบบ (ผู้ดูแล) เพื่อเปลี่ยน PIN (ตัวเลข 6 หลักขึ้นไป) ปรับพิกัดและรัศมี GPS หรือเปิด/ปิด การเช็ก GPS และการถ่ายรูป ค่าจะเก็บที่เซิร์ฟเวอร์และมีผลกับทุกเครื่องทันที

ใส่ PIN ผิด 5 ครั้ง ระบบล็อก 15 นาที เวลา เข้างาน / เริ่มงานบ่าย / เลิกงาน แก้ได้ในหน้าตั้งค่าระบบเลย (เริ่มงานบ่ายใช้กับลาครึ่งวันเช้า) ส่วนช่วงเปิดสแกนอื่นๆ อยู่ที่ Apps Script › Script properties (SCAN_OPEN, SCAN_CLOSE, CHECKOUT_CLOSE)

3. พนักงานเปลี่ยนมือถือ

กดรีเซ็ตในแอป ไม่ต้องแก้ชีต

แท็บ จัดการพนักงาน › การ์ดของพนักงาน › รีเซ็ตเครื่อง/รหัสผ่าน แล้วให้พนักงานเข้าสู่ระบบบนมือถือใหม่ต่อหน้าผู้ดูแลทันที (ใช้กรณีลืมรหัสผ่านด้วย)

4. ดูรูป / ลบรายการ

ดูรูป บันทึกแทน และลบ ทำในแอป

แท็บประวัติลงเวลา กด รูปเข้า / รูปออก เพื่อดูภาพ (รูปไม่เปิดสาธารณะ) ถ้าพนักงานลืมสแกน ใช้ช่อง บันทึกแทน ในหน้าสแกน ระบบจะถามเวลา วันที่ และเหตุผล แล้วเก็บประวัติไว้ในชีต “บันทึกการแก้ไข”

5. ตรวจรายการ “รอตรวจ” (ลาครึ่งวัน / ราชการ / ลืมสแกน)

ตรวจสัปดาห์ละครั้ง ใช้เวลาไม่กี่นาที

  1. แท็บ ประวัติลงเวลา › ช่องสถานะ เลือก รอผู้ดูแลตรวจ
  2. กดปุ่ม ตรวจ ท้ายแถว เทียบกับใบลา/หนังสือไปราชการ
  3. กด อนุมัติตามที่แจ้ง หรือ ไม่อนุมัติ (นับเป็นเข้าสาย) ถ้าไม่อนุมัติหรือเปลี่ยนประเภท ต้องพิมพ์เหตุผลก่อน
  4. กรณี ลืมสแกนเข้า ถ้ารู้เวลามาจริง ใช้ช่อง บันทึกแทน › บันทึกเข้า ในหน้าสแกน ระบบจะคิดสาย/ไม่สายจากเวลาที่ใส่
  5. แถวเก่าที่สแกนตอนเย็นแล้วถูกนับว่า “เข้าสาย 500 นาที” กด แก้สถานะ › ย้ายเวลาเข้าไปเป็นเวลาออก

ทุกการตรวจเก็บไว้ในชีต “บันทึกการแก้ไข” หน้า KPI แสดงลา/ราชการ และลืมสแกน แยกจากช่องเข้าสาย
